# Hack for Humanity Sao Paulo 2026

Este repositorio comeca pela compreensao do problema e do evento. Ainda nao ha ideia de produto, stack ou desenho de agentes aprovado.

## Comece aqui

1. [Dossie de contexto](research/HACK_FOR_HUMANITY_CONTEXT_DOSSIER.md) — evento, trilhas, criterios, dados locais, viabilidade e lacunas.
2. [Dossie publico da banca](research/JUDGES_PUBLIC_BIAS_DOSSIER.md) — perfis, lentes provaveis, convergencias e perguntas adversariais.
3. [Registro de fontes](research/SOURCE_REGISTER.md) — inventario auditavel das fontes e do grau de confianca.
4. [Controle do projeto](docs/agent/PROJECT_CONTROL.md) — estado atual, escopo e gates.
5. [Banco de tarefas](docs/agent/TASK_BANK.md) — o que foi concluido e qual e o proximo ciclo, ainda sem ideacao.
6. [Evidencias](docs/agent/EVIDENCE_LOG.md) — lastro de cada afirmacao operacional.
7. [Base tecnica proposta do Rebobina](research/REBOBINA_TECHNICAL_BASIS.md) — pesquisa complementar com autoria Devin; hipoteses, MVP, riscos e validacao pendente, sem alterar os gates do projeto.

## Regra atual

Antes do OK do time, este projeto permanece em **contextualizacao**. Nao promover ideia, arquitetura, divisao de agentes ou escolha de tecnologia como decisao.
